# AntikPoker: Lobby Return And Participation Panels

Дата: 6 ноября 2026, Europe/Kaliningrad. Статус: **production PASS**.

## Два Исправления

1. Нажатие «Вернуться за стол» в лобби создаёт одноразовое серверное намерение возвращения для авторитетной identity зарегистрированного ACTIVE-участника. AFK сбрасывается после фактического подключения владельца к своему месту. Второе «Я вернулся» за столом больше не требуется. Открытие/обновление лобби и обычный reconnect сами по себе не подтверждают возвращение.
2. На масштабируемых ноутбучных столах AFK-плашка вынесена из высоты панели действий и ограничена свободным пространством рядом со своим местом. AFK и приватные карты больше не отправляют панель в `side-actions` к правому краю. Основные действия, размеры кнопок, текст и стили телефона/большого ПК не менялись.

Намерение возвращения действует две минуты, сохраняется в существующем приватном SQLite snapshot и потребляется один раз. Сам клик не продлевает AFK deadline. Просроченный/pending AFK и выбывшее место не восстанавливаются. Клиент не задаёт player ID или время подтверждения. Зритель не может подтвердить чужой возврат. Новых таблиц, миграций или публичных API нет.
