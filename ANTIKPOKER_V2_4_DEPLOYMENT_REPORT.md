## Ограничения И Ручная Приёмка

- Полный `npm test` финального **f40d226** прошёл локально и на Linux в изолированных временных БД. Production SQLite для тестового набора не использовалась.
- До установки мобильная геометрия входа/регистрации/каталога 320–430px, tablet и desktop, автоматический выбор фото и задержка/ошибка session API проверены в локальном браузере. Runtime-файлы опубликованного RC те же, их хэши при установке сверены.
- **GUI-проверка production не завершена и не отмечается как PASS.** Встроенный браузер дал сетевой timeout; при попытке обычного Chrome инструмент остановился, не сумев надёжно определить URL для проверки безопасности. Обход защит, изменение сети/VPN или дальнейшая UI-автоматизация не выполнялись. Независимые HTTPS-проверки с ПК и VPS прошли.
- Остаётся ручная приёмка реального сайта на ПК/телефонах: визуальная шапка при медленной сети, выбор фото в системном picker, мобильная буква A, обычные столы и полный MTT с аккаунтами/гостями и историей. Рабочие MTT для автоматического smoke намеренно не создавались.
- Несколько SSH-соединений оборвались до аутентификации; повторы успешны. Они не выполняли команд и не создавали дополнительных окон обслуживания.
- В preflight выявлены два тестовых нюанса: отсутствующая намеренно исключённая папка uploads (создана пустой только у кандидата) и гонка ожидания connect в старом тесте ракеты. Исправлен только тест; после этого полный Linux-прогон успешен. Рабочая V2.3 до обслуживания не менялась.
